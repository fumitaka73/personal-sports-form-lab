# 全編チェック（v0.21.0）

「シュートの確認」→ 練習を選択 →「シュート検出チェック」→「全編チェック」を開きます。既存のクイックチェックはそのまま残り、同じ修正ラベルを共有します。

## 画面と操作

以前は候補の前後5秒再生が中心で、全体の時間軸と手動追加は折りたたみの中にありました。全編チェックでは、映像・全練習の時間軸・現時刻／総時間・再生・速度・±3秒・追加・取り消しを1つのコンパクトなワークスペースにまとめました。縦画面は上下、横画面は映像と操作を左右に配置します。細かい操作と説明は下の折りたたみにまとめています。

1. 最初は再開位置で一時停止しています。「再生」を押すと、保存された元動画を時刻順で連続再生します。最初から見る場合は「細かい移動…」→「最初へ」。
2. 時間軸を動かして任意の位置へシークします。表示は練習の保存記録開始からの経過秒です。速度は0.5／1／1.5／2倍。
3. 見逃しを発見したら一時停止し、必要なら「−3秒」や折りたたみの「±0.1秒」で合わせ、「ここをシュートとして追加」。実際に表示した映像の時刻を保存します。別の数値入力は不要です。
4. ●自動検出（青）、▲未検出候補（黄）、◆追加済み（緑）、×誤検出・除外（灰）のマーカーをタップして、その時刻で止めます。自動検出は「正しい／誤検出」、候補は「シュート／違う／あとで」で修正します。
5. 時刻修正は、マーカーを選び、映像の位置を合わせて折りたたみの「選択したシュートをこの時刻に修正」。元の検出時刻は残ります。密集したマーカーは「前のマーカー／次のマーカー」で選べます。色に加え形・時刻・読み上げ名があります。
6. 追加直後の「取り消し」は常時表示。「やり直し」は折りたたみにあります。追加後に再生したい場合は「追加後に再生を再開」をONにします。マーカー付近での自動停止は行いません。
7. 見た範囲を確定するには「見た区間をここまで確認」。再生した区間だけが確認対象です。シークで飛ばした範囲は含みません。薄い緑で確認済み範囲を表示します。全範囲の明示確認が揃った場合だけ「全編を本人が確認完了」と記録します。AI精度を示すものではありません。
8. 「途中で終了・フォームの確認へ」で保存して戻れます。未確認・欠損があっても終了可能。戻った際には同じ練習の全編チェックで保存位置から再開できます。

## 動画の欠けと時刻

青い細いバーは保存映像の範囲、斜線は欠損、下側の薄い緑は明示的に確認した範囲です。メタデータの保存範囲は、区間を読み込んで実際の動画durationが分かった場合に補正します。

約15秒の独立した元動画を1区間ずつ再生し、境界で次へ移ります。大きなBlobの結合・再エンコード・追加コピーは行いません。境界では直前の映像と骨格の合成フレームを保持し、次の映像を読み込んでから切り替えます。完全に無待機の動画結合ではありません。

約0.15秒を超える欠損に到達した場合は停止して「映像なし／保存なし」を表示します。「次の映像」でスキップできます。短い境界の欠けは自動的に次区間へ進み、保存なしの境界として通知・時間軸表示します。時刻は詰めません。欠損時刻の追加は「時刻のみ、動画根拠なし」と保存し、映像があったようには扱いません。録画OFF・容量不足・過去の削除などによる未保存映像は復元できません。

動画、マーカー、修正ラベル、Pose、JSONはセッションの絶対時刻を共通に使い、画面だけ経過秒に変換します。保存姿勢は近いフレーム（±0.12秒以内）を重ね、古い姿勢や映像と異なる縦横比の姿勢は重ねません。姿勢不足でも動画確認・手動追加はできます。

## 保存と互換性

- IndexedDBはv4のまま。元動画・Pose・Good Form・分析結果・点数・元検出・レビュー・Calibration・練習履歴の削除、初期化、再分析は行いません。容量上限や明示削除の既存機能も変更しません。
- `settings/detection-check:<sessionId>` の任意フィールド `fullReview` に再開位置、再生した範囲、明示確認した範囲、本人による全編確認完了日時を保存します。旧レコードにこのフィールドがなくても開けます。
- 手動追加・誤検出・時刻修正は既存の `items/history/past/future` を共有。元のイベント・元時刻は保持。確認範囲の確定もUndo/Redo対応です。
- 再開位置は約5秒ごと、一時停止・シーク・モード切替・画面退出・背景移行時に保存します。保存はrevisionチェック付き。同時変更や容量エラーでは上書きせず通知します。通常の操作は自動保存待ちの後に実行し、追加などの入力を捨てません。
- Safariがプロセスを突然終了した場合は、最後の保存から最大約5秒の位置・未確定再生範囲が失われる可能性があります。追加・ラベル変更は保存完了を確認してください。
- 検証JSONにも新しい任意フィールド・動画根拠の有無を含めます。動画Blobは含めず、従来の元区間書き出しを利用します。外部送信はありません。
- Poseは必要な約5秒の窓だけを最大160フレーム読み込みます。1本の練習全体を姿勢配列として展開しません。動画のObject URLは1区間分で、切替・退出時に解放します。
- この修正だけでレポートの点数・検出率やCalibrationを自動変更しません。完全な正解集合や架空のAI正答率は生成しません。

## 検証と実機で確認すること

単体テストは15秒区間・欠損・座標系、再生と明示確認の分離、旧ラベル互換、Undo/Redo・JSON・映像なし追加を確認します。新規ブラウザテストは合成分割映像で連続再生、シーク、速度、3秒戻し、0.1秒修正、追加、マーカー・誤検出、明示確認・再読込、欠損・手動スキップ、再生拒否後の再試行、既存データ保持を確認します。320×568／390×844／430×932／844×390の主要操作・横スクロールも検証します。

**実機iPhone Safariは未検証です。** サイトデータを削除せず、次を確認してください。

- 長めの新規練習を録画ONで保存し、複数の元区間をまたいで再生・シークできること。
- 縦横回転・アドレスバー開閉・Safe Areaで、映像・時間軸・再生・追加が隠れないこと。
- 動画とPoseが同じ動きを示し、境界の読み込み中は前の合成映像を保持すること。
- 速度変更、密集マーカーの前後移動、0.1秒修正、取り消し／やり直しが片手で行えること。
- 自動再生が拒否された場合に再生ボタンで開始できること。背景移行後は自分で再開できること。
- 欠損は明示され、次の映像への移動で時刻が飛んだことが分かること。
- 一時停止→追加→保存通知→再開、途中終了→再訪で、ラベル・確認範囲・位置が残ること。
- 確認を押していない再生や、シークで飛ばした区間が「全編確認済み」にならないこと。
- 長時間練習の発熱・電池・応答速度、VoiceOver・文字サイズ拡大を確認すること。実機の認識精度・長時間性能は自動テストで測定していません。
