# v0.21.6：ライブコーチの開始・音声・保存

## iPhoneでの使い方（実機で確認する5項目）

1. Safariでアプリを開き、「練習する」→「カメラ開始」。カメラを許可し、全身が映る位置にiPhoneを置きます。縦向き・横向きと前面／背面を試し、全身と骨格が一致することを確認してください。横向きでは映像と操作欄を並べます。どちらの向きでも全身を切り抜きません。
2. 画面に見える「音声を確認」を押します。「音声テストです」が聞こえるか確認してください。聞こえない場合は、音声アドバイスのON、アプリ内の音量、iPhoneの音量・消音設定・Bluetoothの出力先を確認します。Bluetoothの出力先はアプリでは判定できません。
3. 動画・姿勢記録の使用量と残量を確認し「練習開始」。設定の読み込みより前に、タップ直後に音声を初期化します。保存枠不足・録画非対応・保存エラー時は、説明を確認して「録画なしで練習」または「姿勢記録なしで練習」を選ぶか、取り消します。動画なしでは、今回の動画の振り返り・共有はできません。姿勢記録なしでは、後から姿勢再生・検出の再検証ができません。ライブ分析と音声、シュートごとの結果保存は続けられます。
4. 数本シュートし、最初の短い助言とカウントを確認します。保存が途中で失敗した場合は案内が出ます。「続ける」か「終了して保存」を選んでください。保存先全体の空き容量不足・分析停止・練習結果の保存失敗などで続けられない場合は、理由を表示して安全終了します。
5. 「練習終了」後、保存完了の表示とレポートを確認し、履歴からシュート動画を再生します。再読み込みしても、以前のGood Form・動画・フォーム評価・レビュー・Calibrationと今回の記録が残っていることを確認してください。途中の保存失敗では、保存済み区間のみ残ります。Safariのサイトデータは消さないでください。

## 原因と修正

- 以前は録画開始／Pose保存開始の失敗を全体の致命的エラーとして扱い、練習自体が終了していました。動画・姿勢時系列の保存はライブ分析から分離し、ユーザーが選んだ場合に保存なしで続けます。過去データは整理・削除しません。
- 以前は既存保存量込みの80%／85%で警告・終了していました。既存量が多いと、何も撮っていない開始直後に終了し得ました。今は開始前の残量を今回の保存予算にし、その予算内で新規分・保存待ち分を監視します。全体の上限は動画128MiB、姿勢32MiBのままです。端末自体の容量とは別の、Safari内のアプリの保存枠です。
- 開始時に動画16MiB、姿勢180,000B以上の余裕がない場合は、その項目の保存なしの選択肢を示します。練習中も、動画最低8MiB／2分割相当、姿勢10秒相当、結果用8MiBなど従来の終了保存用の余裕を維持します。残量を使い切るまで練習を続ける変更ではありません。`storage.estimate()`の推定が利用可能な場合は実際の保存先の空きも監視します。空きが不明の場合にゼロや十分と断定しません。
- 音声初期化を非同期設定読み込みの前に移し、Safariのタップ操作から直接呼びます。「音声を確認」は折りたたみ設定の外へ移しました。APIが音声要求を受け付けても、実際のスピーカー出力まで保証できるわけではありません。
- カメラを固定高さの横長枠に押し込む代わりに、映像本来の縦横比に合わせて表示枠を作ります。`contain`と既存の座標変換を維持し、鏡像・骨格・ボール・Hoop・タップの座標は同じ映像枠を参照します。
- 書き込み例外で動画保存のコールバックが未処理エラーになる経路と、Poseの同時書き込みが片方だけ残り得る経路を修正しました。失敗時は今回のトランザクションを中止し、理由を呼び出し元に返します。既存記録には触れません。

## 維持するもの・制限

検出閾値・Form Match・Calibrationの内容・IndexedDB v4のスキーマは変更しません。新しいAI改善画面・検証システム・自動削除は追加しません。記録の読み込み時に既存結果を再分析・上書きしません。

シュートが0本になることすべてを解決する変更ではありません。既存の「カメラ表示・ボール・Hoop・診断」から人物の可視関節、手首高さと上昇速度、肘角度、検出フェーズ、推論FPSを確認できます。PR #35の検出修正を維持し、今回の修正では閾値を緩めません。

ブラウザの強制終了、iOSによるサイトデータの削除、端末の故障では保存を保証できません。必要な動画・データは既存の書き出し機能でバックアップしてください。実機iPhone Safariのカメラ、最初の音声、端末の発熱・Safari特有の録画形式は未確認です。

## 開発時の検証

`npm test`、`npm run build`、既存ブラウザテストに加え、`scripts/check-issue-30.cjs`で人工カメラ・人工Poseと独立したテスト用IndexedDBを使用します。個人のJSONや実際の保存データはテストに使用しません。
