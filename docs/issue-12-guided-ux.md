# v0.19.0 操作を中心にした画面と左右比較

## 画面の整理（変更前 → 変更後）

| 画面 | 変更前の課題 | 変更後の操作・表示 |
| --- | --- | --- |
| 基準フォーム | 登録済みか、次に何をするかが説明に埋もれる | 未登録／登録済みと次の操作を先に表示。登録済みなら「練習する」。管理・別動画登録を維持 |
| 練習する | 英語の機能名、レポートへの移動がAI画面にある | カメラ・開始／終了を優先。履歴・レポートを練習画面へ配置。基準なしでは登録へ案内。音声・診断などの設定は日本語・折りたたみ |
| 練習終了 | 保存結果と次の行動が離れていた | 保存成功／失敗を表示し、レポート内から今回のシュート確認・AI改善へ進める |
| シュートの確認 | 練習全体の確認はAI画面の詳細にあった | 練習を選び「練習全体を確認」。各シュートの確認・見逃し追加→本数とボールを放したタイミングの確認を同じ役割に集約 |
| 個別レビュー | 比較結果の数値だけでは姿勢が分からない | 左に保存時の基準、右に今回の保存骨格を表示。本人の肘高さ・ディップ・腰評価、保存して次への操作は維持 |
| AIの改善 | 不明確な「0練習・0実シュート」、リンクの羅列 | 次にやること→操作→準備カード→改善案を表示。調整用と別練習の効果確認用を区別。内部仕様は「改善の仕組み・対象データ」 |
| 練習レポート | 英語タイトル、レビュー・改善の文脈が途切れる | 日本語名、今回の練習を持った確認・改善へのボタン。数値はフォーム一致度でありAI正答率ではないことを維持 |
| 成長の記録 | 長い計算条件、空画面の行き止まり | 期間・項目を選ぶ操作を優先。計算条件を折りたたみ。記録なしでは練習へ案内 |
| 練習履歴 | 分析結果と練習記録の意味が曖昧 | 保存記録の状態と次の操作を表示。練習レポートへ進み、選んだ練習を引き継ぐ |
| 1本の動画分析 | Single Shotなど英語名、基準がない場合の意味 | 日本語名、動画選択→分析という目的と基準の状態を明示 |
| 練習動画の一括分析 | Sessionという名前、長い先行説明 | 日本語名、練習動画の選択を優先。処理・候補検出の説明は折りたたみ |
| 保存済み動画・メモ | 空状態に次の操作がない | 保存本数・動画選択を優先。未登録なら動画登録へ。再生状態・再試行・元動画保存を維持 |
| その他・設定・ヘルプ | 英語画面名、技術情報が操作に混在 | 4タブ＋その他の日本語名を統一。設定・対象データは展開して確認。警告・エラー・保存中は隠さない |
| 確認ダイアログ | 保存の取り消し・承認の意味が重要 | 未保存入力の破棄、承認、復帰、削除の確認を維持。画面の日本語目的・状態と結びつける |

## AI改善の指定文言

- 「AIが見逃したシュートも確認してください。」
- 「AIを改善するための記録：あと○回の練習・○本のシュート」
- 「改善効果を確かめる記録：あと○回の練習・○本のシュート」
- 「1回の練習＝開始から終了までの記録」
- 「確認済みのシュート本数」「AIのアドバイスを評価したシュート数」
- 「AIの調整と、その効果の確認には別々の練習記録を使います。」
- 「一部の過去の動画はAI改善に利用できません。新しく撮影した練習記録を使ってください。」
- 「AIのアドバイスは、内容を確認・評価した記録から改善します。判定が不確かな記録は対象外です。」
- 「撮影条件と基準フォームが同じ記録を使い、AIが改善用と確認用に自動で振り分けます。」

残り回数・本数は既存の実際の検証条件から計算する。調整用2練習・合計20本、**別の**確認用2練習・合計10本。回数と本数を両方満たす必要がある。20本に達しても1回だけなら、もう1回の練習が必要。固定割当・明示除外を維持。

検出改善とフォームアドバイス改善を区別し、本人の評価件数と検証利用件数を混同しない。手首高さ・ディップの助言ルールは検証可能。リリース時の肘高さと腰の閾値・優先順位最適化は収集段階で未対応。モデルの再学習は行わない。

## 自然な操作フロー

1. **練習する**：基準を選び、カメラ開始→練習開始→終了。結果を保存する。
2. **シュートの確認**：練習を選び、動画／姿勢を確認して正誤・本人評価を保存。選択中の練習内で「保存して次へ」を進める。
3. **練習レポート**：同じ練習の結果・全体評価を見る。必要なら個別確認へ戻る。
4. **AIの改善**：同じ練習の撮影条件・基準を引き継ぎ、準備状況→改善案作成→結果比較→承認。次回から適用。以前の設定に戻せる。

「練習全体を確認」では先に全候補を確認し、見逃しを追加する。その後、実本数とボールを放したタイミングを確認する。完全な姿勢記録がない旧練習は理由を表示し、動画レビューへ戻せる。新しい確認結果は既存の自動振り分け関数に渡すだけで、最少件数や独立検証・承認条件を変更しない。

## 左右の骨格比較

個別レビューの「基準フォームと左右で見比べる」を開くと初めて読み込む。保存した基準の分析に対応する姿勢を使い、現在の基準を過去の分析へ無条件に代入しない。アップロード分析は保存された分析フレーム、練習中の記録は該当区間の姿勢を最大600フレーム読み込む。追加のMediaPipe推論や外部送信はない。

- 左：基準フォーム、右：今回のシュート。
- ディップ：見える膝の保存角度が最小のコマ。利用できない側は構え位置と説明する。
- ディップ→リリース、リリース→終了を別々に合わせる。動画長・FPSが異なっても単純な秒数一致で動作を合わせない。
- 「リリースで比較」、動作位置スライダー、少し前／後、同期コマ再生・一時停止、骨格表示切替、片側拡大。
- 同期コマ再生は保存姿勢と映像の静止コマを約10回/秒で表示する。通常の動画の同期音声再生ではない。実際の撮影FPSを復元したコマ送りとも異なる。
- 姿勢と映像の時刻は保存区間の基点を使う。15秒録画境界は元区間を切り替える。録画欠落・削除動画・符号化末尾の不足を補わない。
- 近くの姿勢フレームが0.2秒より遠い場合や人物不在は骨格を表示しない。低信頼度は参考表示、撮影角度が異なる場合は比較限界を表示。
- 動画なしでも保存骨格を表示できる。骨格なしでも映像コマが利用できれば表示する。両方なければ理由を示して通常レビュー・評価を維持。
- 肘の高さ・膝・肩／股関節を見るための表示で、医学的な腰椎角度や新しいAI正答率を生成しない。
- 縦画面は2列＋片側拡大、横画面は広い2列。動画・URL・タイマーを画面離脱時に解放する。
