# v0.21.2 詳細時間軸の使い方

「シュートの確認」→練習を選択→「シュート検出チェック」→「全編チェック」。

以前の数字クラスタと縦の選択一覧はなくなりました。全体の位置バーの直下に、●青（自動検出）、▲黄（候補）、◆緑（追加・採用）、×灰（誤検出）の載った詳細時間軸があります。記号の中心は線上にあり、左右の距離は練習時間の差に比例します。色はフォーム評価ではありません。

1. 詳細時間軸を左右にスワイプして探します。スクロールだけでは動画の位置は変わりません。
2. 記号をタップすると、その動画の位置に移動します。選択中は緑の枠が付き、映像近くに位置・種別・判定が出ます。
3. 映像を見て「正しい／誤検出」または「シュート／違う／あとで」を選びます。微調整、位置修正、取り消し・やり直しは従来どおりです。
4. 密集している場合は「＋」で時間軸を拡大。「−」で縮小できます。極端に近い点や全く同じ位置の点は「前」「次」で1件ずつ選べます。非表示になっている記録も削除されません。
5. 赤い線は現在の再生位置。上の位置バーの青い枠は詳細時間軸の表示範囲です。再生中は緩やかに追従しますが、手動スクロールすると止まります。「現在」で戻り、追従を再開します。

通常の操作に不要な説明・フィルタ・確認済み区間・やり直しは「位置の微調整・使い方」にあります。動画なしの案内、次の映像への移動、クイックチェックも維持しています。

## データと性能

IndexedDB v4のままで、既存の動画、姿勢記録、Good Form、分析結果、Calibration、レビュー、元検出、修正・Undo履歴の移行・初期化・再分析は行いません。時間軸の表示状態はメモリ内です。従来どおり、確認位置・修正操作だけは保存されます。

表示範囲の記号だけ描画し、スクロール要素は最大32,768pxに制限します。長い練習や高倍率では区間を切り替えて全体を辿れます。時間座標を均等間隔に置き換えません。完全に同じ位置の記録には最大倍率でも「前」「次」を使ってください。

## iPhone Safariの実機確認

実機は未検証です。テストはChromiumのモバイル相当サイズと合成動画・姿勢記録で行いました。

- 縦320/390/430px相当・横画面で、動画・操作が下部ナビやSafariのアドレスバーに隠れないこと。
- 17件以上の密集した時間軸で、記号が線上にあること。スワイプで動画が飛ばず、タップで動画とボーンが同じ位置になること。
- 再生中の追従、スワイプ後の停止、「現在」での再開。1時間程度の動画で区間をまたいで移動すること。
- 拡大文字・VoiceOverで、記号の種別・位置・確認状態、前／次・拡大／縮小・現在への移動を確認すること。
- 判定、位置修正、取り消し、再読み込み、動画欠損、動画0区間、フィルタを確認し、元データが残ること。

Safariのスクロール慣性、アドレスバー伸縮、Safe Area、電池・メモリ負荷、VoiceOverの読み上げは実機確認が必要です。サイトデータの削除は不要です。
