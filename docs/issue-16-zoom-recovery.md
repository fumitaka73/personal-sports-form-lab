# v0.19.2 人物ズームとトラッキング復帰

## 原因（コードで確認・再現したもの）

v0.19.1はanalysis.lowQualityが真だと基準フォームのクロップを無条件に全体へ戻していました。lowQualityはPoseの可視性だけでなく、推定リリース、動作量、区間の品質等でも真になります。そのため関節が十分に見える動画でも拡大されませんでした。またクロップは左右両側の肩・股関節が全て高信頼のフレームを必要とし、真横で隠れた側の関節が弱いと失敗していました。

Live Coachの比較基準はフレームを省いたcompactAnalysisです。別保存の基準動画からフレームを取得する際、旧記録でanalyzedAt等の項目が省略されていると、完全一致のチェックが不一致になっていました。今回、履歴の元分析／同じ動画の一致する保存分析から姿勢を取り戻します。指定されている版・解析日時・フェーズ・数値が違う場合は、新しい分析を古い比較へ流用しません。

この再現は旧形式・Low分析の合成データによるもので、ユーザー本人の保存動画・Safariの実機データは未取得です。本人のケースがどの条件に当たるかは、今回追加した画面の理由表示で確認してください。

## 変更と使い方

「シュートの確認」→1本を開く→「基準フォームと左右で見比べる」。

- 自動拡大は分析全体のLowではなく、Poseフレームの関節の信頼度で判断します。少なくとも肩・股関節がそれぞれ1点、合計6点以上の関節が高信頼のフレームを3枚以上必要とします。全ショットの姿勢範囲＋余白で固定し、過大ズームや人物位置の急変時の全体表示を維持。
- 自動／手動／全体表示、実際の表示倍率、クロップの左上・幅・高さを表示。1.0倍で全体のままの場合は「拡大できていません」と理由を表示します。
- 自動不可の基準動画は「人物の範囲を指で囲む」を押し、全体表示になった映像で頭から足までドラッグしてください。元動画・採点・Poseを編集せず、比較表示だけ拡大します。小さい枠でも各軸最低10%を残し、上限10倍を設けます。片側表示にしてから囲むと操作しやすくなります。
- 基準動画の範囲は「この基準動画の範囲を保存」で端末内の別表示設定に保存できます。同じ動画ID・作成日時・サイズ・形式の組合せが一致する場合のみ再利用。設定の形式・座標も検証します。元のGood Formレコードは更新しません。
- 「自動の範囲に戻す」は今回の表示を自動に戻します。保存範囲を置き換える場合は手動で指定し直して再保存してください。
- 姿勢／フェーズのない旧動画でも映像の先頭を表示し、手動で囲めます。動作ボタンでは特定不能の説明を維持します。動画をデコードできない場合は通常レビューで元動画を確認してください。
- 映像と骨格を同じCanvasのクロップ・contain・鏡像変換で重ねます。画面回転や片側表示でも同じ正規化座標を使用し、元動画の向きはブラウザのデコード結果に従います。

## 復帰通知

Live Coachで、既存の関節／全身／人物位置の連続性チェックと追加の0.5秒安定期間を通過すると、トラッキングが安定と扱われます。最初の取得では再開と呼びません。

一度安定した姿勢が1秒以上連続で取れず、その後再び安定した場合に「トラッキングを再開しました」を一度表示・音声通知します。短い途切れでは通知しません。再び十分長く途切れれば再通知します。カメラの向きや切替、セッション終了・再開、画面遷移で状態をリセットします。待機中の古いPoseはシュート検出へ渡しません。保存用の姿勢時系列は引き続き新しく受信したフレームを保存します。

音声ON/OFF、音量0を尊重。コーチ音声が話している間は割り込まず、最大3秒待ちます。新しいコーチ助言や終了が入ると復帰音声は取り消します。音声が出なくても画面の通知を確認できます。端末の消音・音量設定を変更する処理はありません。

## 検証・制限

単体テストは復帰状態遷移、初回・瞬断・連続喪失・停止、音声競合／OFF／0音量、旧compact基準、解析版変更時の流用拒否、真横の隠れた関節、弱いPose、手動範囲・鏡像座標を確認します。ブラウザは合成動画・合成Pose・モック音声で人物ズーム、範囲のドラッグ・保存／再表示、縦横、復帰と初回／瞬断／OFF、二重通知、カメラ切替、終了、古い姿勢の誤検出防止を確認します。

実機iPhone Safariは未確認。実動画の人物取り違え、MP4の向き・シーク、Safariの音声開始許可、タッチ／スクロール競合、消音時の挙動、電池消費は未保証です。サイトデータ消去は不要です。既存IndexedDBの破壊的移行、動画／レビュー／Calibrationの書換えはありません。

### 実機チェック

1. 古い／遠い／精度低の基準フォームで自動拡大と理由・範囲表示を確認。
2. 姿勢なしの動画で、片側表示→人物を指で囲む→範囲保存→比較を閉じて再表示。映像と骨格の位置、ズームOFF・鏡像・縦横を確認。
3. Live Coachをユーザー操作で開始し、初回に「再開」が鳴らないことを確認。
4. 人物が1秒以上退出→戻って安定→音声が一度だけ、瞬断→戻るでは鳴らないことを確認。
5. 音声OFF・音量0では画面のみ。助言発話中、カメラ切替、向き変更、終了・再開、別画面への移動で古い復帰通知が鳴らないことを確認。
6. 保存済みレビュー／JSON／動画再生／AI改善の承認・元に戻すを確認。

実行結果：単体テスト154件（21ファイル）、ビルド、git diff --checkが成功。新規2本と既存8本のブラウザテストが成功（check-issue-16-zoom、check-issue-16-tracking、check-issue-14、check-issue-12、check-issue-10、check-live-coach、check-shot-review、check-personal-calibration、check-issue-1、check-issue-3）。手動指定はマウスPointer EventsとChromiumの合成タッチイベントの両方で確認しました。実機Safariのタッチ確認の代わりにはなりません。
