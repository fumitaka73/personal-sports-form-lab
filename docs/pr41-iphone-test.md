同じChatGPTアカウントでログインしてSafariから開きます。本人のみのアクセスです。本番GitHub Pagesの更新・mainへのマージは行いません。

## iPhoneでの簡単な手順

1. URLをSafariで開き、黄色い **PR41 テスト版 → 動画を試す** をタップ。
2. **写真・ファイルから動画を選ぶ** でHomeCourt圧縮動画（約23MB）を選び、元動画の保存・内容照合完了を待つ。
3. 手・撮影角度を選び、まず **標準・毎秒15枚 → 動画から骨格を読み取る**。画面を開いたまま待つ。黄色い欄の所要時間、フリーズ、発熱を確認。
4. 一度完了した後、取り直しを開始して **処理を中断**。元動画の再生、以前の解析結果・修正が残ることを確認。
5. **骨格を使って再解析**。候補を再生し、ボールが手を離れる瞬間で手動追加・位置修正・取り消し・メモ保存。「読み戻し確認済み」を確認し、再読み込み・再解析後も残ることを確認。
6. Live Coachはテスト用Good Formを新規登録してから **練習する → カメラ → 音声を確認 → 練習開始 → 終了 → 振り返り**。本番のGood Formはコピーしないので、最初は空です。
7. 画面の **所要時間をコピー** で結果のメモをコピーし、発熱などを追記してチャットへ貼り付ける。動画や生の骨格を送る必要はありません。

詳細はテストサイトの **確認手順** をタップしてください。容量不足が出た場合は表示内容と操作をメモし、わざと端末を満杯にしないでください。写真・ファイルの原本を残し、本番・Safariのサイトデータは削除しません。

## 本番・個人データとの分離

- 新規Sitesプロジェクトの本人限定配信。本番 `fumitaka73.github.io` とは別オリジンです。共有範囲を公開・他人向けには変更しません。
- 保存先も `sports-form-lab-pr41-iphone-test` に固定。本番の `sports-form-lab` を開いたり移行したりしません。同じブラウザ内にあっても、本番の既存Good Form・Pose・動画・レビュー・Calibration・履歴は参照／変更しません。
- テスト用に読み込む動画や録画は、このサイト専用のiPhone内IndexedDBに保存します。テストの動画も端末容量を使用します。
- 公開ファイルは確定したPRコミットのコード・MediaPipe配信アセット・確認用UIのみ。動画・生のPose・レビューJSON・`.env`・認証トークン・作業ディレクトリを含めません。
- Content Security Policyでアプリからの接続先を同一サイトに制限。テスト版のGoogle Drive操作を無効にし、Client IDの設定画面も出しません。既存の本番Drive連携設定は変更しません。ログイン・静的アセット配信の通信はありますが、動画・骨格のサーバー送信は行いません。
- 発熱や端末の実メモリ不足はSafariから直接計測できません。体感・OSの表示・画面の反応を記録します。経過時間は実時間で、推論だけのCPU時間ではありません。
- このテストの結果を本番へ自動同期する機能はありません。更新時も専用URL・保存先名を維持し、初期化や自動削除は行いません。iOSによる退避に備えて原本は写真・ファイルに残してください。

## 再現・検証（開発者向け）

`node scripts/build-iphone-preview.mjs --target <新しい専用Siteの絶対パス> --source <PRコミット>` で再現します。先にその専用Siteの `.openai/hosting.json` に、実際に作成された `project_id` と `static.directory=dist` を保存します。ID・資格情報のハードコードやダミー値による公開はしません。

Gitの確定済みコミットだけをarchiveで取り出し、保存先名・Drive無効化・確認用UI・CSPのみを専用コピーへ追加してビルドします。元リポジトリの機能コード・本番用ビルドを上書きしません。置換対象が一致しない場合や、動画／解析書き出しファイル等が配信成果物にあれば停止します。`test-build.json` に元コミット・アプリ版・専用DB名・外部送信停止を記録します。

Sitesの認証トークン・Git書込資格情報はメモリと非表示stdinだけで扱い、公開物・Git・ログに保存しません。配信用tarは `.openai/hosting.json` と `dist/` のみです。

ローカルの専用ビルドを5192番などで配信し、人工H.264動画を指定して以下を実行します。

```sh
OFFLINE_VIDEO_FIXTURE=/private/path/artificial-14s.mp4 \
  IPHONE_TEST_URL=http://127.0.0.1:5192 \
  node scripts/check-iphone-preview.mjs
```

検証済み：本番用v4 DBの全7ストアを同じオリジンへ人工データで用意し、テスト版の起動・保存・再解析・Live Coach使用後も版・内容が変化しない。専用v5 DB・実動画デコード・人工Poseの解析時間表示・中断／再訪／修正保持・骨格再利用、縦横表示、Live Coach開始／音声／終了／保存、Drive無効、外部リクエストなし。既存229件を含む単体233件成功。初期版は物理iPhoneで速度・安定性・保存をユーザーが確認済みです。今回のマーカー・シーク同期の修正はChromiumで検証済みで、物理iPhone Safariでの再確認は未実施です。
