# Session Report / My Progress / 全体フィードバック（Issue #3）

## 使い方

1. **Live Coach**で通常どおり練習し、終了します。結果は**Session Report**に表示されます。「その他」→「履歴」→Live Coach履歴の「まとめを見る」からも開けます。
2. 上部で平均フォーム一致度、検出した候補の本数、有効評価本数、Low本数、前回同条件との差を確認します。「項目別の結果・序盤からの推移」を開くと、ディップ、リリース、肘・肩、バランス、フォロースルー、脚と腕のタイミング、独立した体幹の推定を確認できます。
3. **AIの判定への評価（練習全体）**でディップ・リリース・体幹を正確／不正確／わからないから選び、任意メモとともに保存します。動画を全本レビューする必要はありません。検出・音声は任意です。保存済みの評価は再編集できます。
4. **My Progress · 成長推移**を開き、直近7日／30日、日／週／月、表示項目を選びます。上部の4タブは増やしていません。Live Coach履歴にも入口があります。グラフ下の詳細に実数とサンプル数の表、一括評価の件数があります。
5. 個別確認が必要ならレポートの「個別シュート・従来の集計」→**Shot Review**へ進みます。設定改善は従来どおり「AIの改善」で独立した改善用／確認用データを検証し、明示的に承認してください。

## 数字の定義

- **平均フォーム一致度**: 保存された `comparison.overall` が0〜100の数値で、信頼度High/Mediumかつ除外されていない候補だけの平均。分母は有効な評価本数です。人が正しいシュートと確認した本数や、AIの認識正答率ではありません。総本数は検出した候補数で、実際に打った本数を保証しません。
- **項目別スコア**: 実際の比較エンジンの計測値から導出します。候補内で利用可能なスコアを保存された計測値の重みで平均（重み未保存なら既存METRICSの重み）、その後候補単位で平均します。Low・欠測・除外を数値0へ置き換えません。一部の計測値が欠けていても残りを使うため、見える関節が変わると平均も変わり得ます。
- **ディップ**は `kneeAngle` のみ。`kneeArmTiming` は別の脚と腕のタイミングです。リリースは `armLead / wristPeakTiming / wristHeight`、肘・肩は `elbowAngle / shoulderAngle`、バランスは `torsoLean / bodyOffset / verticalRise / hipAngle`、フォロースルーは `followWrist / followElbow`。
- **対象外の理由**は低信頼度、保存された計測値の欠測、エンジンの除外理由を表示します。理由は計測値単位なので1本に複数つく場合があります。有効評価3本未満は少数サンプルの警告を表示します。3本は「十分な精度を保証する条件」ではなく注意表示の最低条件です。
- **体幹後傾**は既存の `trunkEstimate` の代理角度・Good Formとの差・持続した指摘の本数です。全体と独立した推定の両方がHigh/Mediumで、基準との比較ができる記録を使用します。独立した一致度スコアはないため％を作りません。推定角度の前回差は°でありptではありません。腰椎の湾曲や医学的な反り腰の診断ではありません。
- **従来の集計**は `summarizeCoach` を再利用し、Lowを含む旧平均、最高、安定した計測、次の練習の参考を詳細に保持しています。`buildCoachInput`、保存済みの元の集計や音声は変更しません。
- **前回比**は直前の終了済み同条件セッションとの差。Good Form ID・種別・角度・手に加え、保存された基準分析（計測値・時刻・版・推定用プロフィール・分析日時）、採点版、適用したCalibration IDが一致する場合だけ表示します。不明・混在版・基準の更新・設定変更は比較不可にします。
- **My Progress**は同条件・同じ比較根拠の終了済みセッションだけを使用。候補ごとの有効値をまとめて平均し、セッション平均の単純平均にはしません。日付は端末の暦、週は月曜始まり、月は1日始まり。直近7日／30日は当日を含むローカル日付の範囲です。週／月を選んでも期間外の値は足さないため、端の週／月は一部期間です。線は保存された記録点を結ぶだけで、間の値を測定した意味ではありません。

## 一括評価の保存と互換性

IndexedDBはバージョン4のままです。新しいストアや破壊的な移行はありません。

既存 `review-v04.sessionFeedback['live:<sessionId>']` のコメント等を保持し、任意の `batchRating` を追加します。`session-rating-1` として対象ID、項目評価、メモ、作成／更新日時、対象の分析／採点版、比較条件、適用設定を保存します。同じキーを更新するため重複記録を増やしません。最新のコメント・個別ラベルを読み直して同じIndexedDBトランザクションで更新します。

一括評価は**セッション単位の弱いフィードバック**であり、各ショットが正しい／誤りというラベルに展開しません。ショットの分析・個別レビュー・音声・判定基準・有効なCalibration版を変更しません。My Progressの一括評価欄は正確／不正確／不明の**セッション件数**だけで、正答率％を計算しません。現在のCalibrationの学習・検証入力には使いません。

レビューJSON v1で追加項目も往復でき、古いJSONに項目がなくても読み込めます。対象ID・項目・値等を検証します。既存IDを取り込みで上書きしない従来の方針を維持します。コーチコメントの後日追加で `batchRating` を消さないようにしています。

## 変更ファイル

- `src/session-report.js`: 派生集計、比較条件、前回比、ローカル週／月・期間加重平均。
- `src/session-report-ui.js`: 終了後／履歴レポート、全体評価、軽量SVGグラフ・テキスト表。
- `src/session-feedback.js`, `src/storage.js`: 弱い評価の検証と既存データを保つ保存。
- `src/live-coach.js`, `src/main.js`: 既存の終了・履歴導線へ接続。未保存入力の保護とセッション保存失敗の表示。
- `src/review-data.js`, `src/review-ui.js`: JSON互換性とコーチコメント編集時の保持。
- `src/style.css`: 縦画面・44pxタップ領域・折り返し・グラフ表。既存safe-areaを使用。
- `test/session-report.test.js`, `test/review-data.test.js`, `scripts/check-issue-3.mjs`: 集計・境界・保存・互換性・ブラウザ検証。
