# シュート確認の操作改善（v0.21.1）

チェック画面の「時刻」は **動画の位置** に変更しました。修正対象は **シュートの位置** と表現します。例えば「0:43.5」は動画の開始から43.5秒の位置です。時計の時刻ではありません。内部の秒数・保存形式・過去のコメントは変更していません。

## 新しい操作の流れ

「シュートの確認」→「シュート検出チェック」→「全編チェック」。

1. 動画を再生し、見逃しを見つけたら止めて「ここをシュートとして追加」。選択していない状態では、この追加操作が主操作です。
2. 時間軸の●／▲／◆／×をタップ。近接する点は「＋20」など1つのクラスタになります。タップして開く一覧で1件選びます。時刻ラベルを時間軸に大量に並べず、選択した1件だけを「0:43.5・自動検出・判定未確認」のように動画のそばへ表示します。
3. 動画がその位置へ移動したら、自動検出は「正しい／誤検出」、候補は「シュート／違う／あとで」で保存。未選択時の追加ボタンと判定ボタンは同時に表示しません。
4. 位置がずれていれば、動画を見ながら「−3秒／＋3秒」、選択中に現れる「±0.1秒」で調整し、「この位置に修正」。元の検出位置は残ります。
5. 「前／次」で順に選び、「次の未確認へ」で確認待ちへ進みます。「選択を解除」で連続再生・手動追加へ戻ります。判定保存後に勝手に動画を止めたり次の候補へ移動したりしません。従来のクイックチェックの自動次送りは維持します。
6. Undoは動画のそばで操作できます。Redo、最初へ、確認範囲、保存後の再生、フィルタなどは「位置の微調整・使い方」にまとめています。フィルタは「すべて／未確認候補だけ／自動検出だけ」。未確認候補には「あとで」を含み、確認済みは除きます。

縦画面では動画の下へ時間軸・再生操作・判定と修正を並べます。横画面では動画と時間軸・再生操作を左、選択情報・判定・位置修正を右へ配置します。密集点の一覧は閉じられる小さな選択パネルです。44px以上の領域で1件ずつ選べ、キーボードではEscapeでも閉じられます。

## 記号と色

- ●青：練習中の自動検出
- ▲黄：未検出の候補
- ◆緑：人が追加したシュート、または確認して採用した候補
- ×灰：シュートではないと修正した記録
- ＋数字：その近くに複数の記録。クラスタ自体は中立色です。

**色はフォームのGood／Bad・フォーム一致度を表しません。** 画面内にも短い凡例を表示します。選択中の点／クラスタを囲み、形状・読み上げ名でも区別します。映像の保存範囲・欠損・明示的に確認した範囲は別の細いレーンで表示します。

## 映像がない場合

「次の映像」を欠損位置に直接表示し、折りたたみを探す必要をなくしました。動画OFF・未保存・期限切れ・紐付け違いなどの可能性があり、削除済みとは断定しません。

動画0区間でも保存姿勢・候補があれば確認できます。大きな空プレーヤーは小さくし、正しい位置の姿勢があれば参考表示します。動画の再生・速度は映像がない範囲で無効ですが、姿勢記録の範囲内の位置選択・候補確認・修正はできます。保存映像の復元は約束しません。

全編・クイックとも、映像のない位置へ新しく追加する場合には「動画根拠なし・位置のみ」の確認を表示します。キャンセルした場合はシュートを追加しません。承認した場合だけ既存の修正レイヤーへ記録します。

## 保存とモード切替

保存中／保存しました／保存できませんを表示します。二重タップを抑止し、失敗時は選択・元のラベル・表示位置を保持して再試行できます。映像読み込み中は判定・位置修正を待機させ、直前の映像を別のシュートの根拠にしないようにします。

モードを切り替えても修正ラベル・履歴は共通です。全編は保存した再開位置へ戻り、選択を解除した状態から始めます。クイックの選択と入力途中の追加位置は、同じ練習内の切替で保持します。入力した位置だけで自動追加・自動判定することはありません。別の練習へ切り替えると入力途中の位置は引き継ぎません。

IndexedDB v4・既存ストア・修正データのスキーマは変更しません。動画・Pose・Good Form・元分析・評価・レビュー・Calibration・練習履歴・5件などの既存修正を削除／初期化／再分析しません。全編の再開位置・明示確認・区間再生・JSON出力は既存機能を維持します。再生だけでは全編確認済みにせず、AI設定も自動変更しません。

## 検証と実機確認

新規単体テストは、20件の密集点・1時間の時間軸・320px相当での非重複、全件への到達、フィルタと前後選択を検証します。新規ブラウザテストは20件の一覧選択、判定／位置修正／Undo、動画を見ながらの微調整、未確認への移動、保存失敗・再試行、クイック切替、動画なし追加のキャンセル／承認・二重タップ防止、元動画と過去の修正・レビュー保持を確認します。動画なしのテストは別のPose-only練習を追加し、既存動画の削除を使いません。

**実機iPhone Safariは未検証です。** 自動テストはChromiumと合成動画・姿勢です。認識精度は今回変更・測定していません。

実機ではサイトデータを削除せず、以下を確認してください。

- 17件以上の点が密集する練習で「＋数字」から各記録を選べ、重複タップや読めない位置ラベルがない。
- 縦横回転、アドレスバー、Safe Area、文字サイズ拡大でも動画と主操作・保存通知が下部ナビに隠れない。
- 選択→動画の位置移動→判定／0.1秒調整→保存→次の未確認、が少ないスクロールで行える。
- 動画なし・区間の欠損では「次の映像」が見つかり、追加のキャンセルで記録が増えない。
- クイックと全編を往復・再訪しても修正ラベル、元動画、Pose、Good Form、レビュー、Calibration、確認範囲が残る。
- 実際の15秒区間をまたぐ再生・シーク・姿勢同期、Safariの再生制限と背景移行、VoiceOverの選択パネル・読み上げ、長時間の応答性を確認する。

元の全編チェックの保存条件と制限は [全編チェックのガイド](issue-22-full-check.md) も参照してください。
