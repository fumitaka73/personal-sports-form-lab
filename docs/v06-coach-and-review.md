# Live Coach v0.6：体幹の代理推定・短い助言・レビュー導線

アプリ VERSION 0.14。MediaPipe Pose、Shot Detection、Form Match、保存済み動画、レビュー履歴、承認済みPersonal Calibration設定を維持します。IndexedDBはversion 4をそのまま使い、保存レコードに任意フィールドを追加します。既存レコードの一括変換・再採点・削除は行いません。

## iPhoneでの使い方

1. 同じSafari・同じ公開URLで再読み込みします。サイトデータは消さないでください。
2. Good Form登録で同じ撮影角度の基準を用意します。「登録済みGood Formを管理・選択」から複数の基準や移行した基準も選べます。新規動画の計測は登録画面、分析済み基準の選択・追加は共通のGood Form管理画面です。
3. Live Coachで横／45度を選び、全身を固定カメラに映して練習します。腰の欄は動作中の参考表示を更新し、検出完了後に動作フェーズ比較を表示します。音声は検出後の助言1回にまとめます。
4. 信頼できる指摘がある場合、「腰反りすぎ、ディップ浅い」のように最大2項目を短く読み上げます。Lowの腰推定は数値を参考表示し、読み上げません。
5. Shot Reviewで動画を再生し、「腰反りすぎの指摘」を正しい／違う／判定できないで修正します。修正前のラベルは履歴に残り、元の推定値とForm Matchは変わりません。「助言全体の評価」は2項目を含むフレーズ全体への評価です。
6. Shot ReviewからPersonal Calibrationへ進みます。①レビュー、②改善案作成、③変更前後比較、④承認の順です。練習を別々の調整用・確認用に割り当て、候補作成ボタンを押します。有効な件数が足りなければ残り件数を表示します。
7. 確認用データでも改善した案だけを適用できます。緑の「現在適用中の設定」と黄色の「未適用の改善案」を区別してください。承認後、同じ条件の次回Live Coachから反映します。以前の設定や標準ルールに戻せます。

レビューだけでは自動学習しません。腰のラベルは保存・バックアップできますが、腰の判定基準を最適化する機能は未対応です。

## 腰の指標が示すもの

2Dの肩・股関節・膝の投影幾何を使います。胴体の後傾と肩―股関節―膝の伸展を代理値として表示し、顔のランドマークが明確な場合は向きを決めます。向きが曖昧でも傾きの大きさをLowの参考値として残します。腰椎の湾曲、骨盤前傾角、痛み、医学的な反り腰は計測していません。3D推定値を腰椎角度として扱わず、今回は3Dを使いません。

Good Formと今回の構え〜リリースを0〜1の同じ進行位置で対応付けます。最大80点の小さいプロフィールを分析とともに保存し、全姿勢フレームを省略したLive Coach結果でも残します。旧Good Formに元フレームがあればそこから読み出して比較できます。元フレームもプロフィールもない移行済み基準では、数値はLowの参考値で音声は出しません。同じ角度の基準を登録して確認してください。

- 各フレームの前後0.12秒で中央値平滑化。欠損関節を補間して推定した値にはしません。
- Good Formとの差8°以上、投影後傾10°以上、かつ構えからの変化差6°以上または伸展差8°以上の証拠を要求します。
- 3フレーム以上・0.12秒以上の持続を要求し、0.25秒を超える追跡ギャップでは持続をリセットします。これらは検証済みの医学的閾値ではなく初期のフォーム用ルールです。
- 同じ角度・必要な関節の可視性・向き・開始とリリースの対応が十分なら、横はHigh、45度は最大Medium。角度だけを理由に45度の数値を無効にしません。
- Lowでも数値を表示し、肩・股関節・膝など必要な時系列が得られない場合はN/Aです。Highは追跡・比較条件の品質の目安で、診断の確度ではありません。
- 動作途中の表示は、手首の高さでGood Formの進行位置を近似したLowの参考表示です。確定した検出区間で比較し直した結果だけを保存・音声に使います。

新しい `trunkEstimate` は分析結果・レビュー事例の独立フィールドです。分析の `trunkProfile` は比較用の小さい時系列です。Form Matchの指標、重み、点数は変更しません。従来の横撮影中心のチェック項目は別の詳細欄に保持します。古い結果に新指標を推測で付け足しません。

## 音声

日本語は「ディップ浅い」「ディップ深い」「腰反りすぎ」「リリース低い」「肘の位置」「バランス」「グッド！」「パーフェクト！」などに短縮します。最大2項目、重要度順、1つのspeechSynthesis発話です。重複する同じフレーズはまとめます。数値の採点は変えません。

指摘には項目ごとの可視性を確認します。今回とGood Formそれぞれで必要関節の可視性0.65以上が3フレーム以上、区間の60%以上あり、全体の信頼度もMedium以上であることを要求します。腰は独立した信頼度・持続条件を使います。根拠が弱い項目は画面だけに残します。比較根拠がない、選択範囲の差が大きい、独立した体幹の注意がある場合は、安易にGood／Perfectと言いません。

同じ指摘は項目・方向単位で前回実際に読んだ音声から抑制します。新しい修正助言は最低3秒を空けます。腰は最低2本も空けます。承認済みの優先度・判定基準・より長いクールダウンは尊重します。画面の指摘は消しません。Good／Perfectと撮影案内の従来抑制も残します。

保存された過去の助言には従来の再検証ルールを維持し、新しい助言は新方式で再検証します。2項目の組合せが変わった場合、旧フレーズの評価を1項目だけが同じという理由で良い評価にはしません。腰・新しい組合せの未確認の有益性は推測しません。

## 画面と保存互換性

トップのShot Review / CalibrationをShot Reviewに変更しました。Good Form CalibrationはGood Form管理に変更し、登録画面からも同じ管理画面を開きます。コーチコメントと集計・JSON機能は保持します。レビューと判定改善の操作はそれぞれの画面に分け、相互に移動できます。

Personal Calibrationの実際の条件は変更しません。調整用・確認用にそれぞれ2セッション、検出の実シュート20本／10本、または音声の対象ラベル20件／10件が必要です。検出には全区間の確認・見逃し追加・正解リリース時刻が必要です。使用不能な記録は件数に加算しません。改善未確認では適用ボタンは無効です。専門指標は詳細に残し、表は縦画面でカード表示にします。

新ラベルは `labels.submetrics.trunk` です。以前のレビューと同じ履歴保存・取り消し・JSONを使います。新しい推定と複数助言もJSONに保持します。既存のCalibrationパラメータ、適用ポインタ、保存済み版は保持し、今回の画面整理で上書きしません。

## 検証と未確認事項

合成姿勢による横・45度・鏡像・フェーズ整合、Low数値と音声抑制、欠損、単発ノイズ、追跡ギャップ、2項目・重要度・反復抑制・項目別可視性、新ラベルの履歴／JSON、既存の採点回帰をNodeテストで確認します。

Chromiumの390×844縦画面で、新ラベル保存と再読み込み、元分析・既存設定非変更、4ステップと不足件数、Good Formの共通導線、ページの横はみ出しを確認します。別のブラウザチェックでは、既存動画再生、旧DB更新、改善案の承認、次回Live Coachへの反映、復帰、姿勢バックアップの復元を確認します。

物理iPhone Safari・実際のシュート映像での精度や誤検出率は未検証です。2D投影はカメラ位置、頭の向き、遮蔽、服装に影響されます。実際の練習で指摘と動画を照らし合わせ、違う指摘をレビューに残してください。

```sh
NODE_PATH=/path/to/node_modules node scripts/check-shot-review.cjs
```
