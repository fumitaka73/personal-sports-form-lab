# v0.20.0 練習後のシュート検出チェック

## 保存範囲の調査と安全な方針

Live Coachの録画は、検出されたシュートだけではなく開始から終了までを約15秒ごとの独立して再生できる元区間として保存します。`temporaryVideos`に開始・終了の練習時刻とBlobがあります。録画は全練習で合計128MiBまで、約1.5Mbpsです（新たに保存できる時間は空き容量に依存）。保存待ち、カメラ停止、背景移行、容量不足による境界の欠けはあり得ます。録画OFFは保存しません。

Poseは動画と別に`poseSessions`・`poseChunks`へ練習全体を保存します。14関節、最大20fps、Float32、全体32MiB、1回60分までです。姿勢なしのフレームも記録されます。未取得・保存失敗・途中終了はその状態を保持します。新画面は1候補の前後2.5秒、最大160フレームだけを展開します。候補探索は保存された圧縮チャンクをWorkerへ転送して処理し、全練習の展開済みフレームをメイン画面に保持しません。

今後の練習でも全時間軸の保存を維持し、録画保存時に128MiBをトランザクション内で再確認します。別画面等との競合や上限到達で書き込みできない場合は通知し、既存動画を削除して空きを作りません。既存の7日経過の自動削除を止め、7日は整理の目安に変更しています。Keepしていない元区間も明示的な削除まで残り、容量が埋まると次の録画は停止します。必要な区間の保持・ダウンロードと、確認して不要な区間を削除する従来の管理操作を使ってください。OSによるSafari保存領域の消去は防げないため、重要な動画とJSONは書き出してください。

保存されていない過去の動画やPoseは復元しません。クリップだけ残っていて元区間がないケースも、練習全体が存在するようには扱いません。

## iPhoneでの操作

1. 練習終了後のレポートで「シュート検出チェック」を押します。後からは「シュートの確認」→練習を選択→「シュート検出チェック」で開けます。
2. 検出済み数・未確認候補数・修正済み数を確認します。修正済みには誤検出、候補をシュートとして確定した見逃し、手動追加、時刻の修正を含みます。
3. 「未検出の候補を探す」で保存Poseから探索します。自動候補は正解ではなく、「候補の信頼度」と根拠を表示します。初期一覧は時刻順です。「未検出らしさを優先」に切り替えると確認順も変わります。
4. 一覧を選ぶと前後2.5秒の動画と対応する保存姿勢を自動再生します。「シュート」「違う」「あとで」の1タップで保存し、次の未確認へ進みます。「あとで」は一覧に残り、今回の未確認を終えてから再確認できます。
5. 候補に出ない見逃しは「候補に出ない見逃しを追加・時刻調整」を開き、時間軸をタップして前後を再生→「シュート追加」で登録します。数値入力でも微調整できます。シュート時刻は確認する位置の目印で、候補探索が正確なボール離れの時刻を測定したという意味ではありません。
6. 検出済みを「違う」にして誤検出を修正します。時刻変更は一覧で対象を選び、時間軸／数値を変えて「選択した記録の時刻を修正」を押します。
7. 「取り消し」「やり直し」は再起動後も利用できます。「今回の確認は完了」は未確認・あとでを残して終了します。全編を確認し終えたことや検出率100%を意味しません。
8. 必要な元区間は「保存・書き出し・確認の仕組み」から明示的に保持します。前後がまたがる約15秒の元区間全体を保護します。コピーを増やしません。
9. 「検証用JSONを書き出す」は動画なしのJSONを作成し、保存リンクを表示します。元動画は別の書き出し操作で個別の保存リンクを表示します。必要なリンクを押してiPhoneに保存してください。外部サーバーへ動画・ラベルを送信しません。

## 判定・修正データの区別

- 元の検出、動画、Pose、Form Matchの点数、Good Form、音声助言、個別レビュー、Calibrationは変更しません。
- 確認結果は`settings`内の`detection-check:<sessionId>`に、スキーマ`detection-check-1`として別保存します。IndexedDBのバージョン4と既存ストアは変更しません。
- 初期表示は元の検出と、既存フォームレビューの検出ラベル・手動追加を読み取ります。新画面での修正はフォームレビューに自動で書き戻しません。元時刻・元検出イベント・既存レビュー参照と、修正後の時刻／ラベルを区別します。
- 履歴は変更した項目の差分として残し、取り消し・やり直しも追記します。全項目のスナップショットを毎回保存しないため、iPhoneでの容量増加を抑えます。保存は画面ごとのrevisionを確認して競合を防止します。
- 0.7秒未満の近接登録を防止します。時刻を直すか、誤った対象を「違う」にしてから追加してください。近接する実際の別シュートはこの安全条件のため追加できない場合があります。
- JSONには元検出、候補の根拠・信頼度・優先度・ルール版、本人ラベル、修正履歴、動画とPoseのID・時間範囲、撮影条件、記録方式／適用設定の版を対応付けます。候補探索の版は`loose-arm-rise-1`です。新しい練習ではアプリ版、Poseモデル名、`session-pose-1`の検出ルール版、実際の判定基準も記録します。過去に未記録の版や基準はJSONでnullとし、現在の版に置き換えません。将来の音声／Watchタグも、正解ラベルと入力元を別に記録する形式で拡張できます。

## 候補探索の範囲と限界

既存のライブ検出器・その閾値・承認済みCalibrationとは独立した緩い探索です。シュートする側の肩・肘・手首・股関節の有効姿勢から、約0.2〜1.4秒の手首上昇、肩付近への到達、肘の伸展と複数フレームの継続を確認します。身体上下動は追加根拠です。既存ショットの動作範囲や近傍を除外し、近接候補をまとめます。最大500候補です。信頼度は「中」または「低」で、確率・正答率のパーセンテージではありません。

ボール離れやシュート成功を認識するモデルではなく、挙手などが候補になることがあります。探索で出ない見逃し、腕の欠損、撮影角度・距離の影響もあります。Pose不足は明示し、手動追加を提供します。

今回の確認は局所的な正解ラベルを集める機能です。全練習の完全な正解集合がないためRecallなどを生成しません。レポートの本数・点数を変更せず、既存Calibrationに自動接続／自動学習しません。将来、この別レイヤーをCalibrationの検証入力へ使うには、未確認範囲の扱い、独立した学習／検証割当、時刻整合性と明示承認を追加する必要があります。今回は検証JSONとして利用できます。

対象は終了済みのLive Coach練習です。Single Shot・アップロード動画のSession分析は既存レビュー機能を維持し、この新しい時間軸チェックへの接続は今回含みません。Watch・音声タグ・ネイティブアプリ・App Serverも含みません。
